# 楚河汉界 · 桌面对战

一张低矮漆木桌上的真棋盘，两支玩具军队在上面自己下完一整盘中国象棋，带自动导播镜头。随时可以暂停、改设置或接管一方。

```sh
npm install
npm run dev        # 开发服务器
npm test           # 规则引擎 + AI 测试（Node，无需浏览器）
npm run build      # 打包到 dist/
```

## 分层（严格单向）

```
src/engine/xiangqi.js   规则引擎：纯逻辑，不依赖 Three.js
src/ai/                 rng 种子随机数 · evaluate 评估 · search 分片 alpha-beta · brain 性格/开局库/温度 · commentary 解说
src/game/match.js       一盘对局：唯一能改变对局状态的入口 commit()，只接受合法走法
src/sim/                show 演出协程 · physics 轻量刚体 · fx 扬尘/花瓣/闪光
src/render/             world 桌子棋盘托盘 · figures 玩具人偶 · director 自动导播
src/main.js             总控：引擎决定 → AI 选择 → 演出 → 导播
```

演出层只读走法记录，从不写回对局；物理只负责「倒得像」，结果永远由引擎决定。

## 规则

- 帥/將限九宫；仕/士九宫内斜走；相/象走田、塞象眼不能走、不能过河；馬走日、蹩马腿；車直线滑动；炮走子同车、吃子必须隔一个炮架；兵/卒只进不退，过河后可横走。
- 将帅不能在无遮挡的同一直线对面；走后己方仍被将军的走法非法。
- 将死、困毙（无子可动）都判负；三次重复局面判和；连续 120 步（半回合）无吃子判和；400 步上限判和。
- 记谱用传统写法（炮二平五、馬8進7、前炮平七）。
- 加载时自检：初始局面红方必须恰有 44 个合法走法，结果写入控制台，失败时界面左上角显示红色警告。测试还校验 perft：44 / 1920 / 79666。

## AI 与随机

- 种子（6 位）驱动一切随机：同一种子 + 同样设置 = 同一盘棋。「新种子」「重放该种子」在左上角。
- 评估：子力、位置表、机动性（车马炮可走点数）、将帅安全（缺士缺象）、九宫附近的攻势。
- 搜索：alpha-beta 深度 2–3 加吃子静态搜索，写成生成器按时间片推进（每帧约 8 ms），界面不卡。
- 每局随机的性格：激进炮手、稳守反击、车马冲锋、弃子攻杀，各自偏好不同开局（当头炮、过宫炮、飞相局、仙人指路、起马局 / 屏风马、顺炮、反宫马、卒底炮）。
- 温度滑块：在分数接近的几步里按 softmax 抽选；温度高于 0.55 时偶尔故意失误；激进性格会偶尔弃子强攻。
- 胜率条来自中性评估；每步一句解说（吃子、将军、牵制、捉子、渡河、出车跳马……）。

## 演出

- 车滚轮前进、马跳跃、象迈步、兵列队踏步；经过别的棋子时对方让位，过后弹回，不穿模。
- 炮是投石机：按真实抛体（重力、算出的发射角与飞行时间）越过炮架砸中目标，有闪光和扬尘，界面底部显示发射角与飞行时间。
- 兵刺枪、马扬蹄、车撞、象踏、帅挥剑、士挥扇。
- 被吃的棋子交给刚体模拟：重力、弹跳、摩擦、翻滚、静止，然后抬进两侧托盘或化作花瓣。
- 静止的人偶会呼吸、轻摇，旗帜随风飘动。

## 操作

- 空格：暂停 / 继续；速度 0.25–3×；搜索深度 2/3；镜头：自动导播 / 自由视角 / 俯视（右键拖动或滚轮会自动切到自由视角）。
- 红方、黑方可分别切到「我来下」：点己方棋子显示可走点，再点目标点。
